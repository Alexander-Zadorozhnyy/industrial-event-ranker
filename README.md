# Industrial Event Ranker

ML-система приоритизации инцидентов на логистическом терминале — умный помощник диспетчера. Проект в рамках курса ML System Design (MLSD)

## О проекте

На площадке одновременно работают ричтраки, погрузчики, тягачи и пеший персонал. Диспетчер получает 200–400 событий за смену, из которых 10–20 требуют немедленной реакции. Система автоматически ранжирует активные инциденты по приоритету (P1–P4), выдаёт оценку уверенности и топ-3 объясняющих признака на основе SHAP, а неуверенные случаи направляет на ручной разбор.

Модель не принимает решения о реагировании самостоятельно — окончательное решение остаётся за диспетчером.

**Планируемый стек:** Python, pandas, scikit-learn, LightGBM, SHAP, FastAPI, Docker.

## Установка

Рекомендуется Python 3.12+ и виртуальное окружение.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Линтеры и форматирование

В проекте используется [Ruff](https://docs.astral.sh/ruff/)..

```bash
pre-commit run --all-files
```

Ручной запуск:

```bash
ruff check . --fix
ruff format .
```

Конфигурация Ruff находится в `pyproject.toml`, хуки — в `.pre-commit-config.yaml`.
